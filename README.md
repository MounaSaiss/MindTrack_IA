# EduMind Analytics 🧠

**Student Well-being & Mental Health Risk Factors Analysis**

## 📌 Description

EduMind Analytics is a Data Science and Machine Learning project focused on analyzing student well-being and identifying factors associated with mental health risks.

Using a student mental health dataset, the project explores data patterns, performs data preprocessing and feature engineering, and develops supervised machine learning models for educational purposes.

## 🎯 Objectives

- Analyze student well-being indicators.
- Explore factors associated with mental health risks.
- Clean and preprocess the dataset.
- Build and optimize supervised classification models.
- Evaluate model performance.
- Visualize results and key insights.

## 🛠️ Technologies

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Streamlit

## 📊 Project Workflow

1. Data Audit & Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Data Preprocessing
5. Model Training & Optimization
6. Model Evaluation
7. Automation & Visualization

## 📂 Dataset

[Student Mental Health Risk Prediction Dataset – Kaggle](https://www.kaggle.com/datasets/maqdadali/mental-health-risk-prediction-dataset-students)

## ⚠️ Disclaimer

This project is strictly educational and intended for academic research and data analysis. Its models are not designed for clinical diagnosis, mental health screening, disciplinary decisions, or student selection.
